# Landshop product-deck media integration

Source: user-provided Landshop Product Deck (17 pages) and the four estate/event photo archives.

Required rules:
1. Extract individual property images rather than placing full deck pages with embedded text in web UI.
2. Keep product order DEVELOP → INCUBATE → GROW. The historical deck may call Incubate 'Invest'.
3. Use deck images only for the matching named projects/product types; do not relabel unrelated real estate photos.
4. Banner imagery must not show baked-in marketing captions or mortgage interest/ROI claims.
5. Preserve original brand-logo aspect ratio; do not generate a replacement trademark.
6. Do not publish historical 0%, 6%, 70% ROI, 1% deposit or 10-year financing claims without current approved terms.
7. Prioritize estate originals from provided ZIPs, optimized to AVIF/WebP with responsive sizes and accessible alt labels.
8. Photos used as evidentiary property listings must be actual approved developer/owner imagery; generated lifestyle imagery is editorial only.

Selected individual imagery has been prepared in the accompanying local Landshop Production Foundation ZIP, but has **not** yet been committed to GitHub as binary assets.
